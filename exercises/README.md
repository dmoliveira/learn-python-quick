# Exercises

These problems turn chapter ideas into small work-like tasks. Read the
[exercise guide](../docs/exercise-guide.md) before starting.

```bash
make exercise ID=easy/01_sales_summary
```

Untouched answers raise `NotImplementedError`, so learner behavior checks fail at first. The normal
repository tests only verify that starters import and expose the documented API. Official answers
live separately under [`solutions/`](../solutions/README.md).

- [Easy](easy/README.md): focused Python and parsing.
- [Medium](medium/README.md): tabular data and model metrics.
- [Hard](hard/README.md): leakage-safe design and ranking.
