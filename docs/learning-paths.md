# Learning paths

Pick the smallest path that reaches your goal. Every path starts with the 15-minute orientation in
Chapter 00. Times are rough estimates and include orientation plus exercises.

## ⚡ Fast Python review (5–7 hours)

For engineers who already use another programming language.

1. [Start here](../chapters/00_start_here/README.md): run one example and learn the test loop.
2. [Python fundamentals](../chapters/01_python_fundamentals/README.md)
3. [Data structures and iteration](../chapters/02_data_structures_and_iteration/README.md)
4. [Types, OOP, and Pydantic](../chapters/03_types_oop_and_pydantic/README.md)
5. [Files, regex, and HTTP](../chapters/04_files_regex_and_http/README.md)
6. Solve all four [easy exercises](../exercises/easy/README.md).

**Done means:** you can design a small typed module, parse imperfect input, handle expected errors,
and test the public contract.

## 📊 Data Scientist (11–15 hours)

1. Start with [Chapter 00](../chapters/00_start_here/README.md).
2. Complete the remaining fast review steps above, then:

   1. [NumPy and pandas](../chapters/05_numpy_and_pandas/README.md)
   2. [ML workflows and metrics](../chapters/06_ml_workflows_and_metrics/README.md)
   3. [Trees and XGBoost](../chapters/07_trees_and_xgboost/README.md)
   4. Solve all four [medium exercises](../exercises/medium/README.md).
   5. Read the [metrics field guide](metrics.md).

**Done means:** you can build a leakage-safe tabular pipeline, choose a useful metric, compare a
baseline with a stronger model, and explain uncertainty and failure cases.

## 🛠️ Machine Learning Engineer (20–28 hours)

1. Start with [Chapter 00](../chapters/00_start_here/README.md).
2. Complete the remaining Data Scientist path, then:

   1. [PyTorch and image models](../chapters/08_pytorch_and_images/README.md)
   2. [Embeddings and transformers](../chapters/09_embeddings_and_transformers/README.md)
   3. [Recommenders](../chapters/10_recommenders/README.md)
   4. [FastAPI and MLE](../chapters/11_fastapi_and_mle/README.md)
   5. [Performance and quality](../chapters/12_performance_and_quality/README.md)
   6. Solve all four [hard exercises](../exercises/hard/README.md).

**Done means:** you can train and evaluate a small model, expose typed single/batch prediction
boundaries, reason about ranking and embeddings, and identify what an educational service still
needs for production.

Revisit one solved exercise after 1 day, 1 week, and 1 month. Delete your answer before each retry.

than memory.
