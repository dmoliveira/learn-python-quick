# Learning paths

Pick the smallest path that reaches your goal. Times are rough estimates and include exercises.

## ⚡ Fast Python review (3–4 hours)

For engineers who already use another programming language.

1. [Python fundamentals](../chapters/01_python_fundamentals/README.md)
2. [Data structures and iteration](../chapters/02_data_structures_and_iteration/README.md)
3. [Types, OOP, and Pydantic](../chapters/03_types_oop_and_pydantic/README.md)
4. [Files, regex, and HTTP](../chapters/04_files_regex_and_http/README.md)
5. Solve both [easy exercises](../exercises/easy/README.md).

**Done means:** you can design a small typed module, parse imperfect input, handle expected errors,
and test the public contract.

## 📊 Data Scientist (7–9 hours)

Complete the fast review, then:

1. [NumPy and pandas](../chapters/05_numpy_and_pandas/README.md)
2. [ML workflows and metrics](../chapters/06_ml_workflows_and_metrics/README.md)
3. [Trees and XGBoost](../chapters/07_trees_and_xgboost/README.md)
4. Solve both [medium exercises](../exercises/medium/README.md).
5. Read the [metrics field guide](metrics.md).

**Done means:** you can build a leakage-safe tabular pipeline, choose a useful metric, compare a
baseline with a stronger model, and explain uncertainty and failure cases.

## 🛠️ Machine Learning Engineer (10–14 hours)

Complete the Data Scientist path, then:

1. [PyTorch and image models](../chapters/08_pytorch_and_images/README.md)
2. [Embeddings and transformers](../chapters/09_embeddings_and_transformers/README.md)
3. [Recommenders](../chapters/10_recommenders/README.md)
4. [FastAPI and MLE](../chapters/11_fastapi_and_mle/README.md)
5. [Performance and quality](../chapters/12_performance_and_quality/README.md)
6. Solve both [hard exercises](../exercises/hard/README.md).

**Done means:** you can train and evaluate a small model, expose a typed prediction boundary, reason
about ranking and embeddings, and identify what an educational service still needs for production.

## Retention plan

Revisit one solved exercise after 1 day, 1 week, and 1 month. Delete your answer before each retry.
Change one requirement—for example, missing input or imbalanced labels—to test understanding rather
than memory.
