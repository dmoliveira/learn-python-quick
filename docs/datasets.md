# Datasets and provenance

The machine-readable inventory is [`datasets/manifest.json`](../datasets/manifest.json). Keep it in
sync whenever data usage changes.

## Default policy

- Default examples must run without a network call or API key.
- Prefer scikit-learn `load_*` datasets, deterministic generators, or tiny project-generated files.
- Never use `fetch_*` in a default example because it downloads data.
- Pin a source/version and document terms before adding optional downloaded data.
- Do not commit private, personal, secret, or ambiguous-license data.

## Included learning data

| Data | Use | Network | Notes |
|---|---|---:|---|
| Breast Cancer Wisconsin (Diagnostic) | Binary classification and leakage-safe pipelines | No | Packaged by scikit-learn; see upstream attribution |
| Diabetes | Regression metrics | No | Packaged by scikit-learn |
| Wine | pandas and multiclass examples | No | Packaged by scikit-learn |
| Digits | Small 8×8 image classification | No | Packaged by scikit-learn |
| Generated sales/log/customer/interaction fixtures | Exercises | No | Created by `datasets/generate.py`; interactions include UTC event time for temporal evaluation |

Packaged does not mean suitable for every real decision. These datasets are small and simplify
important social, clinical, and operational context. Use them to learn APIs, not to make real-world
claims.

## Optional data

[MovieLens 100K](https://grouplens.org/datasets/movielens/100k/) is a useful recommender extension,
but its terms restrict redistribution and commercial use. Download it only from GroupLens after
reading its README. The repository's default recommender uses generated interactions instead.

For OpenML or torchvision datasets, record the exact dataset ID/version, source terms, checksum, and
download step. Network-backed examples belong in an explicitly optional path, never in core CI.

## Reproduce fixtures

```bash
uv run python datasets/generate.py --check
uv run python datasets/generate.py --write
```

`--check` compares generated bytes with committed files. `--write` intentionally replaces them.
