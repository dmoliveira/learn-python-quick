# Security policy

This is an educational repository, not a production model-serving framework. Examples use local
data, mocked HTTP, and in-process API tests by default.

Please report a security issue through GitHub's private security advisory feature instead of a
public issue. Include affected files, impact, and a minimal reproduction. Supported security fixes
target the latest `main` branch.

Never include secrets, private datasets, access tokens, or unsafe serialized model files in an issue
or pull request.
