# Code of Conduct

We use the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, patient, and constructive. People arrive with different languages, backgrounds,
and levels of experience. Harassment, personal attacks, and exclusionary behavior are not accepted.

Report conduct concerns privately to the project maintainers through GitHub. Maintainers will review
reports fairly, protect privacy where possible, and take proportionate action.
